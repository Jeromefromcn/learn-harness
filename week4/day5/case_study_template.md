## 架構設計

```
用戶問題
   ↓
Agent Loop (max_turns=6)
   ↓
tools: track_shipment / calc_shipping_fee / check_inventory
   ↓
Harness 層：
  Guides:   系統提示詞（強制 JSON 輸出）
  Sensors:  Pydantic 輸出校驗（計算式）
             LLM-as-judge（推斷式）
  可靠性：   重試 + 斷路器 + 降級
  可觀測性： 結構化 JSON 日誌
  評估：     30 案例數據集 + 評估流水線
```
